# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/koorchik/rust-livr/security/advisories/new), not in public issues.

Examples: a panic, a stack overflow or unbounded memory or CPU use caused by input data or by a schema; input that passes validation although the rules reject it.

You will get an answer within a week. Fixes are released as patch versions of the latest minor version.

|---|---|
