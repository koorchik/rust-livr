# The LIVR test suite

These files are a copy of the test suite of the LIVR specification (`test_suite` in https://github.com/koorchik/LIVR), licensed under the Artistic License 2.0, not under the MIT license of this repository: see https://livr-spec.org/license-and-copyright.html.

They are excluded from the published `livr-core` crate; its tests skip the suite when it is missing. To refresh them: `cp -r ../LIVR/test_suite livr-core/tests/`.
