# livr-core

The engine of [livr](https://crates.io/crates/livr), a Rust validator for the [LIVR specification](https://livr-spec.org) (Language Independent Validation Rules): `Validator`, the rules, `Registry`.

Use the `livr` crate: it re-exports this one and adds typed schemas (`schema!`). The documentation is on [docs.rs/livr](https://docs.rs/livr), the project on [GitHub](https://github.com/koorchik/rust-livr).
