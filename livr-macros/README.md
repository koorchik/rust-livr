# livr-macros

The `schema!` macro of [livr](https://crates.io/crates/livr), a Rust validator for the [LIVR specification](https://livr-spec.org): a LIVR schema checked at compile time, with the Rust types of its output inferred from the rules.

Use it through the `livr` crate, as `livr::schema!`; its documentation is on [docs.rs/livr](https://docs.rs/livr/latest/livr/macro.schema.html). The generated code uses internals of `livr`, so this crate is released with it, at the same version. The project is on [GitHub](https://github.com/koorchik/rust-livr).
